# Задача
Собрать минимум 50 картинок футболистов с разных ракурсов так, чтобы был виден номер на спине. Этот номер в аннотаторе разметить рамочкой: для каждой цифры рамочка своего класса (в итоге 10 классов). Для разметки можно пользоваться любым инструментом (выбрал Label Studio). Экспорт данных - в формате COCO.
